# حسابات الموظفين — التحديث

هذا الإصدار يضيف صلاحيات التعديل والحذف المطلوبة للتقارير والحضور، مع تصدير التقرير الشهري إلى PDF عن طريق نافذة الطباعة في المتصفح (اختَر Save as PDF).

## التعديلات
- الحضور والدوام: المشرف فقط يستطيع التعديل والحذف.
- حساب الموظف/الدفعات: التعديل والحذف للمشرف فقط. الموظف يستطيع الإضافة فقط.
- التقرير الشهري: للمشرف تعديل وحذف الدفعات والمصاريف وسجلات الحضور من داخل التقرير.
- التقرير الشهري: زر **تصدير PDF** يفتح نسخة جاهزة للطباعة بدون القائمة الجانبية، ومن ثم يمكن اختيار Save as PDF.
- حذف السجل ينفذ DELETE فعليًا من PostgreSQL، ومع منع التخزين المؤقت للـ API لا يبقى السجل ظاهرًا بعد الحذف.
- تم الحفاظ على PostgreSQL وRender وطريقة تسجيل الدخول الحالية.

## تشغيل
```bash
npm install
npm start
```

في Render يجب أن تبقى متغيرات البيئة الحالية:
- DATABASE_URL
- SESSION_SECRET
- NODE_ENV=production

## نشر التحديث على GitHub / Render
استبدل `server.js` وملف `public/index.html` بالنسختين الموجودتين هنا، ثم اعمل Commit/Push إلى نفس المستودع. Render سيعمل Deploy تلقائيًا إذا كان Auto Deploy مفعّلًا.


## إصلاح التاريخ
تم تثبيت التاريخ الافتراضي والتقرير الشهري على توقيت **Asia/Gaza** بدل الاعتماد على UTC، حتى لا يظهر اليوم أو الشهر السابق عند تشغيل الموقع على Render.
